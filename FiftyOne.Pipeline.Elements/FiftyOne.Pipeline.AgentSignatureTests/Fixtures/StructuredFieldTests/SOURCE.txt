Files taken, being the ones that bear on what the agent signature element
parses, which is a dictionary or a single item:
  binary.json
  boolean.json
  dictionary.json
  examples.json
  item.json
  key-generated.json
  number.json
  param-dict.json
  string-generated.json
  string.json
  token-generated.json
  token.json

Files deliberately left behind:
  list.json, listlist.json, param-list.json, param-listlist.json, because
  the element never parses a bare list.
  date.json, display-string.json, because the parser implements only the
  RFC 8941 types the three Web Bot Auth headers use, so dates and display
  strings added by RFC 9651 are out of scope.
  large-generated.json, number-generated.json, serialisation-tests and
  the schema folder, because they were not asked for and the first two
  only repeat the coverage of number.json and string-generated.json at
  greater length.
  README.md, generate.py and .editorconfig, because they are not test
  data.

The JSON files and LICENSE.md are held exactly as downloaded and must not
be edited. A refresh means downloading them again and recording the new
commit here.
