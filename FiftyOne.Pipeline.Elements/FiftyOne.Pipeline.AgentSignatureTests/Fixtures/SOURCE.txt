rfc9421_appendix_b.json holds the six worked examples of Appendix B.2 of RFC 9421, HTTP Message Signatures, taken from the published text at https://www.rfc-editor.org/rfc/rfc9421.txt on 1 September 2026. Each entry carries the signature base, the Signature-Input header value and the Signature header value that the RFC prints for that example, together with the public part of the key from Appendix B.1 that the example uses. The RFC wraps its long lines using the convention of RFC 8792, where a line ending in a backslash continues on the next line and the leading whitespace of that next line is not part of the value. Every value here was unfolded by that rule, so the backslashes and the wrapping whitespace are gone whilst the line breaks that belong to a signature base are kept.
